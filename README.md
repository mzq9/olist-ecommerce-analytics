# Olist E-commerce Analytics

## Project overview
This project analyzes Brazilian e-commerce orders to understand sales trends,
customer behavior, delivery performance, and customer satisfaction.

## Business question
Which operational and customer-experience improvements could most improve
revenue, repeat purchases, and satisfaction?

## Dataset
Brazilian E-Commerce Public Dataset by Olist (Kaggle)

## Tools
- SQL
- Python
- Pandas
- Matplotlib
- Seaborn
